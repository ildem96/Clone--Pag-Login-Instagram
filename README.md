# Página de Login do Instagram 

Um projeto simples que recria a interface de login do Instagram, desenvolvido como exercício de aprendizado em desenvolvimento web.

## Tecnologias Utilizadas

- **HTML5** - Estruturação semântica da página
- **CSS3** - Estilização e layout responsivo

## O Que Foi Aprendido

### HTML
Durante o desenvolvimento, foi possível praticar a construção de uma estrutura HTML bem organizada. O projeto utiliza elementos semânticos como `<main>`, `<header>`, `<footer>` e `<nav>`, o que ajuda a criar páginas mais acessíveis e compreensíveis. Também foi aprendido como trabalhar com formulários, incluindo inputs de texto, senha e submit, além de como organizar elementos dentro de containers para melhor estrutura.

### CSS
A estilização do projeto envolveu práticas importantes de CSS moderno:

- **Flexbox** - Usado extensivamente para criar layouts responsivos. O uso de `display: flex`, `justify-content`, `align-items` e `flex-direction` etc,  permitiu organizar elementos de forma elegante e mantê-los centralizados.
- **Responsividade** - Uso de `@media query` unidades relativas para que a página se adapte a diferentes tamanhos de tela.

### Design e UX
O projeto mostrou como decompor uma interface real em componentes menores (banner, form-box, inputs, footer) e como esses elementos trabalham juntos para criar uma experiência visual coerente. Foi aprendido também sobre uso de cores, espaçamento e hierarquia visual.

## Conclusão

Este projeto serviu como base sólida para entender como HTML e CSS trabalham juntos para criar interfaces web. A prática com layout flexível e estrutura semântica são habilidades fundamentais no desenvolvimento web moderno.
